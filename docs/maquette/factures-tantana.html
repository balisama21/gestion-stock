Le modèle par défaut est utilisé pour chaque nouvelle facture. Chaque vendeur garde ce réglage, il ne le choisit pas à chaque fois.

Où ça se règle dans l'application

Paramètres → Documents : modèle par défaut, couleur, logo, mentions, numérotation, ticket.
Sur une vente précise, on peut changer le modèle pour cette facture-là, sans toucher au réglage général.
